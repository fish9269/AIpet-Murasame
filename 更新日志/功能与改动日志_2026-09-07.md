# AIpet-Murasame — 功能与改动日志

> 记录日期：2026-09-07

## 一、插件管理页（完整版）

- **定位说明更正**：插件页统一管控**程序全部功能插件**（桌宠侧 + QQ 侧），不再局限于 QQ；人脸识别、时间同步守护等桌宠功能与活泼/Galgame 等 QQ 功能同页管理
- 每张插件卡片提供：启用开关、`⚙ 设置`（按 plugin.json 的 settings 声明自动生成表单并写回 config.json）、`📁 打开位置`、`🗑 删除`
- **分类筛选**：全部插件 / 官方插件 / 我的插件（带数量角标）
  - 官方插件 = 随程序自带（`plugin.json` 写入 `builtin: true`，现有 7 个已全部标记：空闲自动离线、活泼模式、成人模式、Galgame、网络用语、人脸识别、时间同步守护）
  - 我的插件 = 通过「导入插件 (zip)」导入的第三方插件（导入时自动写入 `builtin: false`，卡片带「我的」橙色标记）
- **切换流畅度优化**：切分类只做卡片显隐，不再整表重建（原先每次销毁重建 7 张卡片导致明显卡顿），并加 160ms 淡入过渡动画
- 文件：`pcl_launcher/plugins_panel.py`、`plugins/<id>/plugin.json`

## 二、主题系统

- **主题目录页分区**：🏛 官方主题 / 📁 我的主题 两个分区并显示数量
  - 官方主题（classic 旧版主题、senrenbanka 千恋万花·樱华）：不可删除；卡片含 应用 / 导出 / 重命名 / 打开目录 / **复制为我的**
  - 我的主题（导入或复制产生）：可 应用 / **修改背景（图片或视频）** / 导出 / 重命名 / 打开目录 / 删除
- **全部主题卡片**都新增「✏️ 重命名」（弹窗改名，写入 theme.json 的 name）与「📂 打开目录」（资源管理器直达主题文件夹，方便替换 assets 图片）
- 「📑 复制为我的」：把官方主题复制一份（id 加 `_copy` 后缀、`builtin=false`）后即可自由改背景等细节，官方主题保持原样
- 导入的主题 zip 一律强制标记为「我的主题」，即使原包导自官方主题
- 主题数据结构：`themes/<id>/theme.json`（id / name / builtin / accent / colors / decor 樱花装饰 / nav_icons 导航按钮图 / background 背景 / widgets 圆角等）
- 千恋万花主题已应用：自定义按钮图标（图标文件夹素材）、背景图片/视频壁纸、樱花装饰、卡通圆角按钮
- 文件：`pcl_launcher/themes_panel.py`、`pcl_launcher/colors.py`、`pcl_launcher/themes/`

## 三、启动器外观与背景

- 移除标题栏左上角绿色方块 logo、左侧「模型列表」标题旁的绿色方块图标（顶部只留导航按钮）
- 左侧模型列表改回**白色底**（不再透明露底）
- 右侧 Live2D 预览区背景：主题壁纸**整张拉伸填满**预览区（GLSL 330 着色器 + legacy 双路径），保证看到完整整图；无壁纸时用主题底色，不再出现白块/透明露桌面/只显示半张图
- 右侧各卡片/输入框/弹窗采用白色半透明底，主题壁纸可透出
- 窗口背景支持：主题壁纸图片（cover 铺满）、视频循环播放、透明度调节
- 文件：`pcl_launcher/main_window.py`、`pcl_launcher/widgets.py`

## 四、人脸识别联动

- 人脸管理功能并入「插件 → 人脸识别」（照片库在顶部「人脸」页，识别参数在插件设置里）
- 停用「人脸识别」插件 → 顶部「人脸」导航自动隐藏；重新启用自动恢复
- 文件：`pcl_launcher/main_window.py`、`pcl_launcher/widgets.py`

## 五、设置页更新日志入口（本次新增）

- 设置界面最底部新增 **📜 更新日志** 区块，三个按钮：
  - `查看日志`：弹窗阅读本文件夹内最新一篇更新日志
  - `导出日志`：把最新日志另存为副本（.md）
  - `打开目录`：在资源管理器打开 `更新日志` 文件夹
- 本文件即通过该文件夹维护：`更新日志/功能与改动日志_YYYY-MM-DD.md`
- 文件：`pcl_launcher/widgets.py`

- 打包仍走 PyInstaller onedir（ASCII 路径虚拟环境 `C:\aipet_build_venv`），产物为根目录 `AIpet-Murasame.exe` + `_internal/`
